W firmie elektro-bud potrzebna jest aplikacja okienkowa do zarzadzania stanem magazynowym. 
Program ma zapewnic latwa,szybka i sprawna usluge dodawania, przegladania i usuwania nowych pozycji w systemie.

wymagania funkcjonalne: 
dodawanie produktow.
przegladanie i usuwanie produktow.
walidacja danych (EAN, sektor, półki).
czyszczenie formularza po dodaniu wlasnego produktu.
powiadomienia o blednych danych.

wymagania niefunkcjonalne:

program musi byc aplikacja okienkowa napisana w WPF z wykorzystaniem jezyka C#.
interfejs - prosty, czytelny, estetyczny i latwy do odnalezienia sie.
szybkosc aplikacji - program dziala szybko, odpowiada na zadania uzytkownika natychmiastowo bez zacinania sie, opoznien.
